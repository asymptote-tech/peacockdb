# bugfix-proposals

Raw material behind [`../corpus-fixes.md`](../corpus-fixes.md), read at `188c23ce`. Nothing
here was built or run; every file is a reading of the tree.

- `00-tickets.md` — the 27 tickets that keep a corpus cell disabled, with the evidence line
  for each.
- `NN-proposal.md` — one analyst's localized-fix proposal for ticket #NN, with a minimum
  corpus query.
- `NN-review.md` — an independent analyst's critique of that proposal; it saw the proposal,
  never the proposer's reasoning.
- `digest-A..D.md` — one reconciled record per ticket, proposal against review, in four
  groups: A aggregates, B device export, C joins and empty lanes, D scan limits and
  expressions.
- `10-fixes-v1.md`, `11-fixes-v1-review.md`, `20-fixes-v2.md`, `21-fixes-v2-review.md` — the
  two consolidation rounds: 27 tickets grouped into fixes, critiqued, revised, critiqued again.
  `corpus-fixes.md` is v2 with the second critique applied.
- `prompts/` — the instruction each role was given, for a re-run.
